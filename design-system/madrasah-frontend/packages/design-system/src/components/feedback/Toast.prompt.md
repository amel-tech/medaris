Bottom-right confirmation toast — used after imports and saves in Nizam.

```jsx
<Toast title="İthal Kartlar" description="2 kart başarıyla içe aktarıldı." />
<Toast tone="info" title="Müfredat kaydedildi" anchored={false} />
```

Anchored by default, so the containing panel must be `position: relative`. Copy is plain
and factual — no exclamation marks, no emoji.

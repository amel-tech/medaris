How the shell is built

One sidebar on the paper surface, --layout-sidebar wide, with a hairline at inline-end. It holds the logo, the köşk the manager is working in, the sections, and the signed-in person at the foot. At night the whole shell turns to ink.

The main region is data-density="compact": 32px controls, 8/12 table cells, 16px card padding. Titles are Literata; everything else is 14px sans. The page has one ink button, “Celse planla”.

A top-level page like this one has no breadcrumb. A page below it (a course, a session) shows one above its title.

Below 768 the sidebar is not drawn. The AppBar takes its place: the menu button, the mark, the page's name and at most two actions. The menu opens the nav sheet, a native modal <dialog> at inline-start with the same sections and items, ending with the signed-in person. Esc, the close button, the backdrop and a followed link close it; focus returns to the menu button.

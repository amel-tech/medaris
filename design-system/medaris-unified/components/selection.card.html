Checkbox and radio share one 16px box and differ only in radius — --radius-xxs against --radius-full; the label around each is the 24px target. A switch commits immediately; a checkbox waits for a submit. If a control needs a Save button next to it, it is not a switch. Open, not fixed: the unchecked boundary is 1.47:1 (OPEN-3) and the switch off state 1.23:1 (SPEC-D3-21).

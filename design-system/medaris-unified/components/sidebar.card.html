There is one sidebar, on the paper surface, in Nizam and Nazır. At night it turns to ink with the rest of the page. Tedris uses a top bar instead.

The current page is a lâciverd tint, ink text at 600 and a lâciverd glyph. The link itself carries aria-current="page".

A count names what it counts with a hidden word (“5 bekleyen”). A lock says the page waits on something; the page it opens says why. Items the viewer cannot use are not drawn.

The signed-in person ends the sidebar: one link to the settings page, where “Çıkış yap” lives. Below 768 the AppBar sheet holds the same items and ends with the same link.

Inverse · light

The inverse surface is the canonical müderris shell: the current item takes the brand fill. .mds-nav--light on the <nav> draws the same items on white, with a brand tint and semibold text for the current one — every screen ported from #95 uses it until SPEC-D3-04 is decided.

A count sits at inline-end with a visually hidden word after it (“5 bekleyen”); on the current item it inverts. A lock says the course waits on something; the page it opens says what.

The current item is aria-current="page" on the link itself. Items the viewer's roles cannot use are not drawn.

.mds-nav-user ends every nav: the signed-in person, one link to the settings page, where “Çıkış yap” lives. AppBar's sheet ends with the same link below 768.

Ratios are WCAG 2.x relative luminance, computed from the hex values in tokens/semantic.css. Text pairs are held to 4.5:1 because the entire control layer is 14px Medium — below the 18.66px/bold threshold that would allow 3:1. Focus and control boundaries are held to 3:1 under WCAG 2.2 Non-text contrast and Focus appearance.

The input border row has no clean token fix: gray-300 at 1.47:1 is the file's value for every field outline, and raising it to gray-400 only reaches 2.2:1. Fields are still identifiable by their white fill against the slate-50 page, which is itself only 1.05:1 — so in practice an input on a white card has no perceivable boundary. That is a design decision to take, not a token to swap, and it is the largest open item in this system.
